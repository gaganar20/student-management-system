# Student Management System

A Python console application to manage student records.

## Features
- Add a new student
- Update student details
- Search by roll number or name
- Display all students
- Delete a student
- Input validation
- Data saved in a JSON file

## Technologies Used
- Python
- JSON

## How to Run
1. Install Python
2. Download student_management.py
3. Run: python student_management.py

## What I Learned
Functions, loops, conditions, dictionaries, file handling and input validation.
